# Handoff format

Use this structure in the task note's append-only history. Fill every field with real results; write `not run` or `not available` where appropriate.

- Task ID / agent / session / UTC date:
- Scope completed:
- Files and commit/PR (or exact local artifact paths):
- Checks actually run and observed results:
- Acceptance criteria still unchecked:
- Limitations and blocked reason, if any:
- Exact next action:
- Review outcome / reviewer / integrated revision (filled at acceptance):

Do not include tokens, credentials, raw conversations or private user data. Keep failed attempts and superseded decisions visible.
